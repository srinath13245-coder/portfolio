# 🚀 Srinath A – Dynamic Portfolio Website

## 📌 Project Overview
This is a modern and interactive personal portfolio website built using **HTML, CSS, and JavaScript**.  
It showcases my profile, technical skills, education, and contact details with smooth 3D tilt effects and animated mouse trail particles.

---

## 🎯 Features

- ✨ Modern dark UI design
- 🎨 Google Poppins font integration
- 🖱 3D Card Tilt Animation
- 🌟 Mouse Trail Particle Effect using Canvas
- 📱 Fully Responsive Layout
- 🔗 LinkedIn Integration
- ⚡ Smooth Hover Effects

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Glassmorphism & Gradient UI)

- About Me

---

## 🎮 Interactive Effects Explained

### 1️⃣ 3D Tilt Effect
- Uses `mousemove` event
- Calculates cursor position inside card
- Applies `rotateX` and `rotateY` transform
- Creates 3D hover animation

### 2️⃣ Mouse Trail Particles
- Uses HTML5 Canvas
- Generates particles on mouse movement
- Gradually fades and expands particles
- Creates smooth glowing trail effect
